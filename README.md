### 🛠️ Projetos em Destaque

- [**Aurum-Lab-MVC**](https://github.com/Isaque-Codes/Aurum-Lab-MVC) — Sistema de gestão laboratorial focado em escalabilidade e organização de processos.
  - **Destaques Técnicos:** Arquitei a aplicação utilizando o padrão **MVC (Model-View-Controller )** no ecossistema **.NET 9**, implementando uma clara separação de responsabilidades. Estruturei a camada de **Services** para isolar a lógica de negócio e utilizei **Dependency Injection** para garantir um código testável e desacoplado.
  - **Stack:** .NET 9, ASP.NET Core MVC, C#, Entity Framework Core, SQL Server, HTML5, CSS3.

- [**Safezone 🛡️**](https://github.com/Isaque-Codes/Safezone) — Ecossistema de segurança IoT com autenticação biométrica e monitoramento em tempo real.
  - **Destaques Técnicos:** Implementei uma arquitetura de comunicação baseada no protocolo **MQTT (Publish/Subscribe )** para integração entre múltiplas unidades ESP32. Desenvolvi o firmware em **C++** utilizando **Programação Orientada a Objetos** para gerenciar sensores de impressão digital, luz, movimento e pressão, garantindo processamento assíncrono e baixo consumo de recursos.
  - **Stack:** C++, ESP32, MQTT (HiveMQ), Arduino Framework, JSON (ArduinoJson), Sensores IoT.

- [**APIRESTJava**](https://github.com/Isaque-Codes/APIRESTJava) — API robusta para gerenciamento de catálogo de mídia com foco em integridade de dados.
  - **Destaques Técnicos:** Projetei a persistência de dados com **Spring Data JPA**, resolvendo desafios complexos de modelagem como relacionamentos **Many-to-Many** através de tabelas de junção explícitas. Implementei o padrão **DTO (Data Transfer Object )** para proteger a camada de domínio e utilizei **Jakarta Bean Validation** para garantir a consistência das entradas via endpoints REST.
  - **Stack:** Java 17, Spring Boot 3, Spring Data JPA, Hibernate, MySQL, Maven, Swagger/OpenAPI.
